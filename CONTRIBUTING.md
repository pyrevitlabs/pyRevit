# Contributing to pyRevit

Thank you for helping. There are several ways to contribute.

## Report a bug or ask for a feature

Open an issue on [GitHub](https://github.com/pyrevitlabs/pyRevit/issues/new/choose) and follow the template. [Reporting issues](docs/help/reporting-issues.md) explains how to collect the information that helps most.

For questions and ideas, use the [pyRevit forum](https://discourse.pyrevitlabs.io).

## Improve the documentation

The documentation lives in the `docs/` folder. See [Documentation and tutorials](docs/contribute/documentation.md).

## Translate pyRevit

See [Translate pyRevit](docs/contribute/translate.md).

## Change the code

1. Fork the repository and create a branch from `develop`.
1. Set up your environment with the [Developer's guide](docs/dev-guide.md).
1. Follow the [code style](docs/pyrevit-style.md) and the [testing policy](docs/testing.md).
1. Open a pull request against `develop`.

[Repository organization](docs/repo-organization.md) and [Understanding pyRevit Architecture](docs/architecture.md) describe where things are.

Maintainers: see [CI/CD and release flow](docs/ci-cd.md) for the tag-driven release process.
