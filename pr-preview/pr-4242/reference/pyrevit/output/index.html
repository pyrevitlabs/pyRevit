    output

    Provide access to output window and its functionality.

    This module provides access to the output window for the currently running pyRevit command. The proper way to access this wrapper object is through the :func:get_output of :mod:pyrevit.script module. This method, in return uses the pyrevit.output module to get access to the output wrapper.

    Examples:

    from pyrevit import script
output = script.get_output()

    Classes

    PyRevitOutputWindow()

    Bases: object

    Wrapper to interact with the output window.

    The output window is an html-rendering console that scripts print to. This wrapper exposes the documented Python API for it: printing (html, markdown, code, tables, images), drawing charts, managing window geometry and icon, driving the progress bar and log panel, and saving the rendered contents.

    Each wrapper binds at construction to one ScriptOutput: the running command's own window, or the shared session window when no command is running (e.g. session load). The binding is cached for the wrapper's lifetime, so retaining the wrapper also retains the correct output for deferred and modeless callbacks after the command returns.

    Members not listed here are forwarded to the underlying ScriptOutput .NET object.

    Examples:

    from pyrevit import script
output = script.get_output()
output.set_title('My Report')
output.print_md('### Results')
for i in range(10):
    output.update_progress(i + 1, 10)

    object.__setattr__(
        self, "linkify", functools.partial(self.linkify, output=output)

    Attributes

    window property

    PyRevitLabs.PyRevit.Runtime.ScriptConsole: Return output window object.

    renderer property

    Raise: the legacy IE WebBrowser renderer was removed.

    The output window now renders with Microsoft Edge WebView2 (Chromium). There is no live DOM object to reach for; use :func:inject_to_head, :func:inject_to_body, :func:inject_script, :func:add_style, and :func:print_html instead.

    output_id property

    str: Return id of the output window.

    In current implementation, Id of output window is equal to the unique id of the pyRevit command it belongs to. This means that all output windows belonging to the same pyRevit command, will have identical output_id values.

    output_uniqueid property

    str: Return unique id of the output window.

    In current implementation, unique id of output window is a GUID string generated when the output window is opened. This id is unique to the instance of output window.

    is_closed_by_user property

    Whether the window has been closed by the user.

    last_line property

    Last line of the output window.

    debug_mode property writable

    Set debug mode on output window and stream.

    This will cause the output window to print information about the buffer stream and other aspects of the output window mechanism.

    supports_messages property

    bool: Whether the page can exchange messages with Python.

    False when the window falls back to plain text (e.g. the WebView2 runtime is missing) or has been closed by the user. Scripts should check this and fall back to a printed report.

    Note

    Opens the output window and starts its renderer if needed, without waiting for it, but never reopens a window the user closed.

    on_message(handler)

    Register a handler for messages the output page posts to Python.

    The page sends with window.chrome.webview.postMessage(value). The handler receives the JSON-decoded value (dict for a posted object) and runs in Revit API context through :func:pyrevit.revit.events.execute_in_revit_context, one call per message in arrival order. Return values are ignored; answer with :func:post_message. Handlers are released when the window closes.

    Warning

    execute_in_revit_context is IronPython-only. Under CPython handlers run directly on the UI thread, outside Revit API context, so they can update the page but cannot read or modify the model.

    Parameters:

    Name Type Description Default
    handler function

    handler(message); a plain function or method, as required by execute_in_revit_context

    		 required

    Returns:

    Type Description
    bool

    False when the window cannot receive messages; see

    def on_message(self, handler):
    """Register a handler for messages the output page posts to Python.

    The page sends with ``window.chrome.webview.postMessage(value)``. The
    handler receives the JSON-decoded value (``dict`` for a posted object)
    and runs in Revit API context through
    :func:`pyrevit.revit.events.execute_in_revit_context`, one call per
    message in arrival order. Return values are ignored; answer with
    :func:`post_message`. Handlers are released when the window closes.

    Warning:
        ``execute_in_revit_context`` is IronPython-only. Under CPython
        handlers run directly on the UI thread, outside Revit API
        context, so they can update the page but cannot read or modify
        the model.

    Args:
        handler (function): ``handler(message)``; a plain function or
            method, as required by ``execute_in_revit_context``

    Returns:
        (bool): False when the window cannot receive messages; see
        :attr:`supports_messages`.

    Important:
        Handlers outlive the command, so the bundle must run on a
        persistent engine (``engine: persistent`` in ``bundle.yaml``).

    Examples:
        ```python
        output = script.get_output()

        def select_elements(message):
            revit.get_selection().set_to(message["ids"])

        if output.on_message(select_elements):
            output.print_html(
                '<button onclick="chrome.webview.postMessage('
                '{ids: [1234]})">Select</button>'
            )
        else:
            output.print_md("Interactive actions need the WebView2 runtime.")
        ```
    """
    if not self.supports_messages:
        return False
    window = self._runtime_output().window
    if self.__dict__.get("_message_window") != window:
        self._message_handlers = []
        subscription = self.__dict__.setdefault(
            "_message_subscription", self._dispatch_message
        )
        window.WebMessageReceived += subscription
        self._message_window = window
    handlers = self._message_handlers
    if handler not in handlers:
        handlers.append(handler)
    return True
