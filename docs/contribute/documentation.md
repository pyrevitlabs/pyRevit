# Documentation and tutorials

This site is built from the `docs/` folder of the pyRevit repository with MkDocs. The Python API reference is generated from the docstrings in `pyrevitlib/pyrevit`.

To improve a page, edit its Markdown file and open a pull request against `develop`. Build the site before you push:

```bash
mkdocs build --strict
```

Tutorials are welcome, both written guides for the [Tools](../tools/index.md) pages and videos. Share them on the [pyRevit forum](https://discourse.pyrevitlabs.io), or add them to the relevant page with a pull request.

See [Contributing](../CONTRIBUTING.md) for the workflow.
